## Checked and fine
- **RSA size limits:** `rsa` 0.10 accepts 1024–8192 bits.
- **Commitment outputs are never written raw** (asserted in a test).
- **`wrap_rebind` always destroys** its temporary KEK and copy, also on error.
- **The If-None-Match and orphan-cleanup paths** cannot destroy pre-existing objects: creation
  requires an empty locator.
- **Hook contract:** exit 0 always, protocol-only stdout, paths from the map only, existing paths
  only.
- **cryptoki patch fallback:** the HMAC key-type guard refuses rather than misidentifying when the
  patch is missing.
